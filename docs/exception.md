# Exceptions au cadre de l'organisation

**Projet personnel** (décision du builder, 6 novembre 2026).

Les recommandations de l'organisation ne sont pas suivies dans ce projet : fiche d'intention validée, dépôt privé, hébergement interne, etc.

Seules ses obligations restent appliquées :
- aucun secret dans le code ;
- respect du RGPD ;
- respect de l'AI Act ;
- PostgreSQL comme base de données.
